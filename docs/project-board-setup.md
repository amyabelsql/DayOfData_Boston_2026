# Project board setup

1. Open the repository Projects tab and create a project.
2. Choose a board layout.
3. Add a Status field with these values
   - Backlog
   - Ready
   - In Progress
   - In Review
   - Done
4. Add a single select field named Environment with Dev, Test, and Prod.
5. Add a single select field named Risk with Low, Medium, and High.
6. Add a date field named Change Window.
7. Link the repository and add the demo issues.
8. Move each issue across the board as the work progresses.

Use the board during the talk to show how a report moves from a request to review and completion.
